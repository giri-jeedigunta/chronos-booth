
# 🕰️ Chronos Booth

**Chronos Booth** is a world-class AI-powered "time-travel" photo booth. Using cutting-edge Google Gemini technology, it allows users to transport themselves into various historical scenes, from Ancient Egypt to a Neon Cyberpunk Future.

> **Special Note**: This project was built during the **GDG Stockholm** event using **Google AI Studio**.

## 💰 Troubleshooting & Billing
If you see a **"Permission Denied"** error, it's because high-quality image generation requires a billing-enabled API key.

**Good News:** You can use your **$300 Google Cloud free trial credits**!
1. Activate your trial in the [Google Cloud Console](https://console.cloud.google.com/).
2. Link your billing account to a Google Cloud Project.
3. In [Google AI Studio](https://aistudio.google.com/), select that project in the dropdown and generate an API key.
4. Select that key in this app when prompted.

## ✨ Features
- **Quantum Photography**: Real-time camera capture or archive upload.
- **Subject Analysis**: Gemini 3 Flash analyzes your features and "temporal aura".
- **Thematic Soundtracks**: Each era features immersive background music.
- **Reality Refiner**: Tweak and edit your historical photos using natural language.

## 📖 How to Use
1. **Grant Access**: Allow camera permissions.
2. **Capture**: Snap a photo or upload an image.
3. **Pick a Destination**: Choose an era (e.g., *Neon Future*).
4. **Manifest**: Wait for the AI to reconstruct history around you.
5. **Refine**: Use the text box to add details (e.g., "Add a laser sword").
