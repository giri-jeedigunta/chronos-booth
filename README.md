# 🕰️ Chronos Booth

**Chronos Booth** is a world-class AI-powered "time-travel" photo booth. Using cutting-edge Google Gemini technology, it allows users to transport themselves into various historical scenes, from Ancient Egypt to a Neon Cyberpunk Future.

> **Special Note**: This project was built during the **GDG Stockholm** event using **Google AI Studio**.

## ✨ Features
- **Quantum Photography**: Real-time camera capture or archive upload.
- **Subject Analysis**: Gemini 3 Pro analyzes your features and "temporal aura" to ensure a perfect historical match.
- **Thematic Soundtracks**: Each era features immersive, royalty-free background music with a dedicated temporal harmonizer (music player).
- **Reality Refiner**: Tweak and edit your historical photos using natural language prompts.
- **Cinematic Visuals**: High-fidelity image generation via Gemini 2.5 Flash Image.

## 🛠️ Built With
- **Engine**: React 19 & TypeScript
- **AI**: [Google Gemini API](https://ai.google.dev/) (@google/genai)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Space Grotesk & Playfair Display

## 📖 How to Use
1. **Initiate Sequence**: Grant camera permissions or upload a portrait from your device.
2. **Temporal Lock**: Wait for the "Quantum Signature" analysis to complete.
3. **Select Destination**: Choose a historical era from the "Destinations" list on the right.
4. **Manifest**: Watch as the AI reconstructs the space-time continuum around your portrait.
5. **Refine**: Use the "Reality Refiner" to add specific details (e.g., "add snow", "make it sepia").
6. **Archive**: Download or share your historical masterpiece.

## 📦 Local Development
To run this project locally:
1. Clone the repository.
2. Ensure you have an API Key from [Google AI Studio](https://aistudio.google.com/).
3. Set your environment variable: `API_KEY=your_key_here`.
4. Open `index.html` in a modern web browser or use a local development server like `vite` or `live-server`.
