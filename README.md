
# 🕰️ Chronos Booth V2.0

**Chronos Booth** is a world-class AI-powered "time-travel" photo booth. Using cutting-edge Google Gemini technology, it allows users to transport themselves into various historical scenes, from Ancient Egypt to a Neon Cyberpunk Future.

> **Special Event**: This project was built and presented during the **GDG Stockholm** event: [Code at the Speed of Thought: Architecting Creative AI with Gemini & Antigravity](https://gdg.community.dev/events/details/google-gdg-web-stockholm-presents-code-at-the-speed-of-thought-architecting-creative-ai-with-gemini-amp-antigravity/).

## 🔑 Obtaining API Keys
To manifest historical imagery, high-quality models like `gemini-2.5-flash-image` are used. These require a billing-enabled API key.

1.  **Activate Google Cloud Credits**: Head to [Google Cloud Console](https://console.cloud.google.com/) and activate your $300 free trial credits.
2.  **Create a Project**: Ensure a billing account is linked to your project.
3.  **Get Key from AI Studio**: Visit [Google AI Studio (ai.google.dev)](https://aistudio.google.com/), select your billing-enabled project, and generate an API key.
4.  **Local Run**: If running locally, you can enter the key in the **System Config** (Settings icon) within the app.

## 🛠️ Technical Implementation
- **Frontend**: React 19, Tailwind CSS (Neubrutalism Design).
- **AI Models**:

- **Styling**: Retro-Flat / Neubrutalism aesthetic for high contrast and readability.

## 📖 How to Use
1. **Grant Camera Access**: Required for quantum photography.
2. **Capture**: Snap a photo or import an archive portrait.
3. **Pick a Destination**: Eras unlock only after a portrait is detected.
4. **Refine Reality**: Use the Refiner to add details (e.g., "Add a golden crown").
